# 16. Руководство администратора

Админка — **дополнительный** модуль MVP, не обязательный кабинет исходного конкурсного сценария.

Демо-вход: email `admin@demo.ru`, пароль `demo1234`.  
Регистрация admin через UI `/register` **недоступна** — роль выдаётся seed/Backend.

Адрес: http://localhost:8080/admin (после логина редирект с `/admin` → `/admin/overview`).

Если стенд собран с `VITE_USE_MOCKS=true`, админка работает на MSW; в стандартном compose моки выключены и UI ходит в FastAPI.

---

## 1. Вход

1. Открыть `/login`.
2. Ввести `admin@demo.ru` / `demo1234`.
3. Попасть в `/admin/overview`.

Не публикуйте иные административные пароли продакшена.

---

## 2. Overview

Маршрут `/admin/overview`.  
KPI, недавние события, статус API (read-only с `GET /api/admin/overview`).

---

## 3. Пользователи

Маршрут `/admin/users`.

1. Найти пользователя в списке.
2. Заблокировать / разблокировать → `POST /api/admin/users/{id}/status`.
3. При блокировке сессии отзываются на Backend.

---

## 4. Assessments / Categories

- `/admin/assessments` — вкладки каталог / шаблоны / попытки / аналитика (в основном просмотр).
- `/admin/categories` — справочники; UI помечает редактирование как «позже».

---

## 5. Offers / Vacancies

`/admin/offers`, `/admin/vacancies` — списки для модерационного обзора (read).

---

## 6. Чего нет в UI

Отдельного экрана Audit Log нет (события пишутся в `audit_events`).  
Создания категорий/вопросов через админ-UI нет.
