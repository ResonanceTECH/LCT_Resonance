## Несоответствия / пробелы

1. Официальный PDF ТЗ не приложен к репозиторию — нумерация разделов «2, 2.1…» оригинала здесь не верифицирована дословно.
2. Server-side PDF экспорт не сделан.
3. Нет опубликованных метрик Precision@K / NDCG@K на экспертной разметке.
4. Real FSP API отсутствует (ожидаемо).
5. Отдельного «опроса по отрасли» как wizard нет — специализация выбирается в профиле/тесте.
