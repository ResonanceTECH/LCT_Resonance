Адреса (после Docker-стенда): приложение http://localhost:8080  
Локальный Vite: http://localhost:5173  
Письма подтверждения (Docker): http://localhost:8025  

Демо-аккаунт: email `candidate@demo.ru`, пароль `demo1234`.

Ниже — только экраны, существующие в `frontend/src/app/router.tsx`.

---

## 1. Регистрация нового кандидата

| Поле | Значение |
| ---- | -------- |
| Экран | Регистрация |
| Маршрут | `/register` |
| Назначение | создать учётную запись |

Пошагово:

1. Открыть приложение в браузере.
2. Нажать переход к регистрации (с лендинга или `/register`).
3. Выбрать роль **Кандидат** (candidate).
4. Ввести email, пароль, имя (поля формы на экране).
5. Принять согласия, которые требует форма (обязательные чекбоксы).
6. Отправить форму → попадаете в кабинет `/candidate` с access token в sessionStorage.
7. Подтвердить email:
   - Docker: открыть Mailpit http://localhost:8025 → письмо → ссылка подтверждения;
   - локальный dev без SMTP: смотреть лог backend (`email_not_sent`) или заголовок `X-Verification-Token` при `APP_ENV=dev`.
8. При необходимости нажать «Отправить письмо снова» в баннере кабинета.

Ошибки: слабый/короткий пароль — валидация формы; занятый email — сообщение API; в prod без SMTP регистрация может вернуть 503.

## 5. Тестирование

| | |
| -- | -- |
| Старт | `/candidate/testing` |
| Сессия | `/candidate/testing/:sessionId` |
| Результат | `/candidate/testing/result` |

Пошагово:

1. Открыть «Тестирование».
2. Выбрать специализацию и предполагаемый грейд.
3. Начать сессию → 10 вопросов по одному.
4. Ответить на каждый (пропуск = ошибка).
5. Завершить → увидеть score и статус прохождения.
6. При ≥ 70 — категория подтверждена; смотреть в профиле verified-поля.

Ограничения: TTL 30 мин; cooldown пересдачи 24ч для того же/выше грейда; смена confirmed категории ≤1 раз / 90 дней.  
Провал не понижает уже подтверждённый грейд.
