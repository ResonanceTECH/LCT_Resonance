# 15. Руководство работодателя

Адрес UI: http://localhost:8080 (Docker) или http://localhost:5173 (Vite).  
Демо: `employer@demo.ru` / `demo1234` (Игорь Смирнов, Resonance Labs).  
Второй работодатель: `employer2@demo.ru` / `demo1234`.

**Важно:** для отправки офферов email должен быть подтверждён. У seed-аккаунтов email уже verified.

Создание опубликованной вакансии **не обязательно** блокирует оффер логически на уровне продукта: потребность описывается вакансией (в т.ч. draft); подбор идёт через Talent Pool с `vacancyId`.

---

## 1. Регистрация и вход

1. `/register` → роль **Работодатель**.
2. Заполнить форму, принять согласия.
3. Подтвердить email (Mailpit http://localhost:8025).
4. `/login` → кабинет `/employer`.

---

## 2. Дашборд

Маршрут `/employer`.  
Сводка + аналитика (`/api/dashboard/employer`, `…/analytics`): воронка, конверсии (как отдаёт API).

---

## 3. Компания

API `GET/PUT /api/employer/company`.  
Профиль компании создаётся/обновляется; при создании вакансии `companyName` может зафиксироваться снимком в вакансии.

---

## 4. Описание потребности (вакансия)

| | |
| -- | -- |
| Список | `/employer/vacancies` |
| Создание | `/employer/vacancies/new` |
| Редактирование | `/employer/vacancies/:id/edit` |
| Карточка | `/employer/vacancies/:id` |

Пошагово:

1. «Новая вакансия».
2. Указать название, специализацию, грейд, вилку зарплаты **в рублях**, формат работы, навыки (обязательные/желательные), статус (draft/active).
3. Опционально: вставить текст → «разобрать» (`POST /vacancies/parse`) — эвристики, не LLM.
4. Сохранить.

---

## 5. Talent Pool

Маршрут `/employer/talent-pool`.

1. Выбрать вакансию в фильтрах (параметр `vacancyId` в URL).
2. Дождаться списка кандидатов **только подтверждённой категории** вакансии.
3. Смотреть Match Score и краткие причины.
4. Открыть карточку кандидата.
5. При необходимости отметить несколько и перейти в Compare (`/employer/compare?ids=…`).

Фильтры дебаунсятся (~300 мс) и живут в query string.

---

## 6. Карточка кандидата и оффер

Маршрут `/employer/candidates/:id`.

1. Изучить профиль (без контактов), skill radar, ФСП.
2. Добавить в shortlist при необходимости.
3. Отправить предложение: заполнить форму оффера, **обязательно зарплату в RUB**.
4. Отправить → статус pending у кандидата.

Ошибки: `EMAIL_NOT_VERIFIED` если почта работодателя не подтверждена; валидация валюты/полей.

---

## 7. Shortlist и Compare

- `/employer/shortlist` — сохранённые кандидаты, удаление.
- `/employer/compare?ids=id1,id2` — матрица 2–4 человек.

---

## 8. Исходящие офферы и контакты

Список: `/employer/offers`.

После того как кандидат **принял** предложение:

1. Открыть карточку кандидата.
2. Запросить / открыть блок контактов (UI дергает `GET /api/candidates/{id}/contacts`).
3. До Accept ожидайте сообщение о блокировке (`CONTACTS_LOCKED`).

Контакты после Accept доступны этому работодателю (по правилу unlock), не «всем работодателям сразу».
